# coolest-art-01

A make.fun bounty entry: a stdlib-only Python program that procedurally renders a black hole eclipse with a glowing accretion ring as a PNG.

## Run

```sh
python3 main.py
```

The program uses only the Python 3.13 standard library — no third-party packages are needed. It writes the generated artwork to `/output/entry.png`.
